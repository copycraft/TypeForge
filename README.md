
# TypeForge

**TypeForge** is a terminal-based typing tester that helps you improve your typing speed and accuracy with fun animations and live feedback.

```
+----------------------------------------------------------+
| 1. Download the latest release from the Releases page.  |
|                                                          |
| 2. Open your terminal (Command Prompt, PowerShell,      |
|    or terminal on Linux/macOS).                          |
|                                                          |
| 3. Run the application:                                  |
|      java -jar TypeForge-1.0.jar                         |
|                                                          |
| 4. Follow the prompts in the app:                        |
|    - Press Enter to start the forging animation         |
|    - Type the text shown in the terminal                |
|    - View your WPM and accuracy at the end              |
+----------------------------------------------------------+
```

## Features

- Epic ASCII banner and forging animation  
- Typing test with WPM and accuracy tracking  
- Fully terminal-based — works on Windows, Mac, and Linux  

## Requirements

- Java 17 or higher installed on your system  
- Terminal that supports ANSI colors (for colored text)
